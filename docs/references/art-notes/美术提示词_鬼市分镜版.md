# 《义乌鬼市 · 夜行百物志》美术概念图提示词（分镜版）

> 用途：AI 生图落地美术概念。中文版适配即梦/通义万相等，EN 版适配 Midjourney/SD 等。
> 风格骨架词（每张必须保留）：低多边形 / 平涂色 / 无描边 / 低面数 / 烘焙光影；EN: low-poly / flat-shaded / toon / baked lighting。
> 色基调：夜青黑 × 黛蓝铺底，灯笼暖橙点光。

## 视角技术约定（与程序侧对齐）

- 漫游态：固定 45° 斜俯 2.5D 镜头，看不到的面（建筑背面、屋顶内侧）不做。
- 交易态：触发式运镜切至摊主正面平视中景（0.8–1.2s 插值过渡），离开切回。
- 两个机位可见面之和 = 全部建模范围，资产量最小化。

## 使用建议

1. 先生成镜头 1 与镜头 3 定画风；确定后把这两张图作为垫图 / 风格参考，其余镜头沿用其风格描述。
2. 角色（镜头 7）与场景分开生成，建模阶段再统一低模化。
3. 如需指定比例：场景图建议 16:9，角色三视图建议 3:2。
