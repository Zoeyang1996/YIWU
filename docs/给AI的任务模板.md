# 给 AI 的任务模板

下面的内容可以直接复制到项目内的 AI 对话。完成后在浏览器检查实际结果。

## 首次创建应用

请先读 AGENTS.md、README.md、开发进度和技术方案。检查当前目录与运行环境，完成 T01：创建最小可运行的 Three.js 网页应用，显示正交相机下的地面和牌楼占位模型。保护现有设计文件，沿用已经存在的技术配置。请运行必要检查并提供实际预览方式，更新 README 和开发进度。本次只做技术起点。

## 实现一个交互

请读取设计框架和开发进度，本次实现【任务编号和具体行为】。用户操作是【操作】，应该看到【反馈】。保留【已有行为】。验收条件是【两至四条可观察结果】。完成后运行相关检查，给出预览和验收步骤，说明未验证部分，并更新进度。

## 调整画面

当前【页面或位置】的【物体或界面】呈现为【现象】，希望调整为【目标】。请参考【具体图片路径】，重点采用其中的【配色、比例或构图】，保留现有【交互行为】。先实现局部调整，再给我查看结果。

## 修复问题

我在【页面】执行【复现步骤】后出现【现象】；预期是【结果】。报错原文是【粘贴完整错误】。请定位并修复原因，检查相邻流程是否仍正常，不重建整个项目。说明原因、修改和验证结果。

## 保存已验收版本

我已验收本次【功能】。请检查 Git 差异，确认只包含本任务相关内容，不含密钥或不必要的大文件，再创建描述清楚的本地提交，告诉我提交编号和内容。远程推送按我另行指示执行。

## 开始新会话

请读取项目规则、设计框架、开发进度和决策记录，检查当前 Git 状态。先概括现在已经实现什么、尚未验证什么，然后继续完成【任务编号】。不要依据旧资料覆盖最新决定。
