# 验收清单

这是待执行清单，勾选只表示对应版本已实际检查。每轮在开发进度中记录测试设备、浏览器、结果和限制。

## 基础运行

- [ ] 按 README 中的命令能够启动，浏览器能打开实际预览地址。
- [ ] 首次加载、刷新和窗口缩放没有白屏或遮住主要按钮。
- [ ] 无阻断运行的报错；加载失败有可理解的提示或重试方式。

## 首页三时段

- [ ] 滚轮与按钮均能选择午市、夜市、早市。
- [ ] 牌楼主体位置稳定，环境和至少一个物体状态连续变化。
- [ ] 快速连滚、反向滚动和过渡中点击入市不会错入其他时段。
- [ ] 不使用滚轮也能进入任一市集。

## 街道和摊位

- [ ] 角色能够往返，不穿过柜台或建筑；行走方向符合屏幕直觉。
- [ ] 牌楼、近景棚顶和建筑不持续挡住角色及道路。
- [ ] 点远处摊位后走到可达交互点，再开始运镜；新目标能替换旧目标。
- [ ] 平视镜头看清摊主与主商品，右侧面板不遮挡主体。
- [ ] 关闭摊位回到正确位置，反复开关不会卡住镜头。

## 商品与购物车

- [ ] 商品列表可滚动，滚动不影响首页时段或角色。
- [ ] 商品可旋转并复位，无模型时仍可通过图片或文字浏览。
- [ ] 规格、数量、价格、小计和合计一致；重复加入遵循合并规则。
- [ ] 切换市集、返回首页、刷新后，购物车按设计保留。
- [ ] 模拟结账明确说明未支付；取消结账不丢购物车。

## 导航与异常

- [ ] 任意市集可以回首页，也可以换市；首次访问从入口开始。
- [ ] 关闭商品恢复原摊位及列表位置；浏览器返回行为合理。
- [ ] 打开购物车时底层界面不误响应点击、拖拽或移动键。
- [ ] 商品或场景加载失败可恢复；反复换市不会累积动画循环和监听器。
- [ ] 若移动端列为本轮范围，触屏能完成选时、移动、逛摊和商品查看。
