## 本轮实现

- 安装现有声明的 npm 依赖，生成 `package-lock.json`；运行时 Node 24.19.0。修复清单脚本中 CommonJS 与 ES 模块不匹配及 `/public` 资源路径问题。
- 重做总览布局：宣纸底色、朱砂印记、青瓦木架与微缩市集。持续保留牌楼和街区主体，午夜早可滚轮连续切换，也可直接点选。
- 四个独立交互摊位，三时段招牌、对白、人物状态与灯光不同。夜间四位志怪摊主；茶摊早间蒸汽、灯笼发光、棚帘变化。

- 六件程序化三维商品，带完整体积，可旋转、缩放、复位；选择规格会改变商品颜色。模型不可用时保留矢量图和商品信息。
- 全局行囊支持商品规格合并、数量上下限、勾选合计、移除、本地恢复以及模拟结账。确认后只移除勾选项，不采集地址、不产生真实支付。
- `/market/noon`、`/market/night`、`/market/morning` 独立入口；摊位、详情与面板由 URL 状态表示。
- 场景和商品查看释放动画、观察器、输入监听、几何体、材质与纹理；GLB 异步完成会检查实例是否仍有效。
- 接入用户参考文件夹中的 1.03 MB GLB，保留来源记录。其余模型为代码制作，非下载的正式成套美术资产。
- 新增 `启动预览.cmd`，本机可双击启动；更新 README 和素材记录。

## 限制与尚未验收

- 视觉符合参考的低模青瓦、木架、布棚与暖灯方向，但不宣称达到参考图全部手绘纹理和人物精度；正式美术须由用户判断。
- 当前是有界直街，未制作完整浅 S 街区、多支路和复杂寻路；通过布局及选摊时隐藏该棚顶减少遮挡。
- 商品、价格和对白均为展示内容，正式商品来源和交易服务尚未确定。
- 未进行真实手机、低端 GPU 长时间帧率测试；未做 WebGL 丢失、网络断开等故障注入验收。
- 无正式环境音、配乐、演示视频或公开演示链接。
