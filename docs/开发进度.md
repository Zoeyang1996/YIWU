### 已实现

- 海图长卷连接六港：支持滚轮缩放、拖拽平移、港口名册点选，新增触屏可用的“近览／远览／全卷”按钮；移除过期占位弹窗。返回画卷保留当前港口，地址支持港口英文标识以及旧版数字参数。
- 港口抵达可选择下船或继续启航。角色从福船沿舷梯下船，随后进入街道；提供方向键／WASD、点地行走、触屏方向按钮和探索点快捷入口。
- 点人物、货摊、建筑后，角色沿有界网格绕过柜台、灯柱与牌楼到交互点，再切换正交近景与对话。漫游和近景具有不同镜头高度与俯角；货摊近景隐藏棚顶及前方牌楼、旗幡，桌面为右侧对话栏留出空间。
- 六港使用不同名称、人物对白和商品组合；新增双塔、七层塔、红砖塔、亭阁、圆顶宣礼塔等地标体块差异。街道骨架仍共用，美术为程序化演示模型，不是历史复原。
- 保留六件三维商品；支持拖拽旋转、缩放、复位、款式／数量选择和加入行囊。修正商品首帧朝向、居中与尺寸适配；窄屏上下排列，文字区域可单独滚动，打开时从名称和价格开始显示。
- 商品预览关闭时停止最新动画帧、取消输入监听、断开尺寸观察并释放专属三维资源，保护共享色阶纹理。模型创建失败仍保留文字资料与选购；主场景创建失败或 WebGL 中断提供重新加载入口。
- 新增 `silk-road-cart.js` 与 `silk-road-ui.css`：画卷及所有港口共用远航行囊，按商品 ID、款式与单价合并，本地恢复；支持修改数量、移除、勾选、合计、确认／取消模拟结账。明确说明无真实支付或发货。
- 对话与详情地址可直接打开；按钮、Esc 与浏览器返回按层级恢复。深链接关闭当前层时处理站内地址，不强制跳出页面。行囊打开时暂停场景行走；滚轮和拖拽限定在所属画布。
- 新增 Vite 多入口配置，使原首页与三个独立演示页均进入生产构建；沿用 npm 和既有依赖。

## 本轮新增（YIWU2 海上丝绸之路 · 一级页面双方案）

依据 `YIWU2/海上丝绸之路方案大纲.doc`，在 `demos/` 下新增两个独立 HTML 演示，仅实现一级页面，二至四级页面（下船探索、特写对话、商品详情）留占位提示，待用户选定一级方案后再接入。

- `demos/silk-road-planet.html`（方案一 · 星海航球）：三渲二低模星球，青绿海面 + 八片陆地洲屿，六座港口城镇（泉州、广州、占城、马六甲、古里、忽鲁谟斯）带塔楼／灯塔、栈桥与灯笼；滚轮驱动朱帆福船逐港远航（球面插值 + 弧线起伏），拖拽转动星球，点击港口或左侧名册直航；抵港弹出「下船探索／继续启航」卡片；支持 `?port=N` 直航参数。
- `demos/silk-road-scroll.html`（方案二 · 海图长卷）：垂直俯视的立体画卷，Canvas 手绘宣纸海图（海浪纹、朱砂航路虚线、祥云、港口墨字、海丝印章、绫子边）+ 低模浮雕建筑、山峦、帆船、浮云、飞鸟；滚轮缩放、拖拽平移（均带边界约束），点击港口或名册飞镜入港并弹出同款卡片；支持 `?port=N` 参数。
- 两页共用宣纸米白 / 青绿 / 朱砂 / 暖木的统一配色与 MeshToon 三渲二材质；`demos/vendor/` 内置 three.js 0.180 运行库副本，演示不依赖项目源码。
- 两页互相切换链接；WebGL 创建失败时显示说明与重试按钮，不白屏。
- 从方案 doc 中提取三张内嵌参考图归档至 `docs/references/images/`（见素材清单）。
