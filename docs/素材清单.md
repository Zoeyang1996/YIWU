# 素材清单

目前只有策划与美术参考资料，没有已确认的正式网页模型或商品数据。已建立分类目录，见 `public/assets/README.md`；代码制作清单在 `src/data/assets.ts`。场景现用代码生成的几何体占位，不属于正式 GLB 模型。以下候选用于安排后续制作。

| 资产 | 当前状态 | 首轮用途 | 验证重点 |
| --- | --- | --- | --- |
| 牌楼与首页微缩市集 | 待制作 | 首页占位场景及三时段变化 | 主体轮廓稳定、变化明显 |
| 浅弯主街与道路 | 待制作 | 角色移动和摊位布局 | 遮挡、碰撞、行走方向 |
| 主角小满 | 名称与身份候选 | 第三人称操控角色 | 远景可辨认、行走和站立 |
| 灯笼精灯铺 | 策划候选 | 夜市灯具展示 | 悬挂陈列、亮灭反馈 |
| 青蛙货郎玩具摊 | 策划候选 | 发条玩具与拨浪鼓 | 柜台试玩、商品细节 |
| 狐妖饰品镜铺 | 策划候选 | 饰品与化妆镜 | 平视构图、陈列分区 |
| 三维商品样板 | 待选品 | 至少一件环绕查看 | 背面完整、旋转复位 |
| 商品图片与信息 | 待提供 | 其余商品详情与列表 | 来源、规格、演示或真实价格 |

每个正式资产补充：资产 ID、文件路径、来源与使用权限、所用场景、文件大小、材质纹理、动画、当前状态。参考图片不能直接标为完成的模型。

推荐命名使用稳定英文 ID，例如 `stall_frog_toys.glb`、`product_rattle.glb`，中文名称放入商品数据。模型按统一尺度、朝向和原点导出，先用占位角色检查比例。保留网页导出文件，体积较大的建模源工程另行归档。
