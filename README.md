# 义乌三时市集 YIWU

基于 Three.js、TypeScript 和 Vite 的国风互动市集。主目录为 `C:\Users\Administrator\Documents\GitHub\YIWU`。

## 当前可用体验

- 总览：同一座牌楼与街区，滚轮或按钮切换午市、夜市、早市；光色、灯笼、棚帘、摊主和晨间蒸汽随时间变化。
- 街道：正交第三人称漫游，WASD／方向键、点击地面、触屏方向按钮；点击摊位先走到柜台，再平滑切换为面向摊主的近景。
- 四个摊位：玩具、灯铺、书铺、茶食。夜间对应青蛙货郎、灯笼精、猫妖书生和可爱饕餮。
- 六件三维商品：拨浪鼓、发条青蛙、兔子灯、宫灯、手账与茶盏；拖拽旋转、缩放、复位、款式变色和数量选择。
- 行囊：按商品与规格合并，跨市共享，本地保存；支持数量修改、移除、勾选与模拟结账。**不产生真实支付或发货。**
- 窄屏：触屏行走、底部摊位栏、可滚动详情与行囊。

当前是完整主流程的可运行美术原型，不是所有正式美术与商品资料已定稿的成品。参考文件夹的一份 GLB 已接入，其他建筑、人物和商品是按参考结构制作的程序化模型；没有把参考图片伪装成三维模型。

## 本机快速打开

双击仓库里的 `启动预览.cmd`，按终端提示打开 **http://127.0.0.1:5173/**。保留终端窗口，关闭窗口会停止服务。不要双击 `index.html`。

当前机器已安装项目依赖；启动脚本会优先寻找 Node.js，也支持本机 Codex 已有的 Node 运行时。脚本不会自动下载软件。

## 标准开发命令

安装 Node.js 22.12+ 和 npm 后，在项目目录执行：

```powershell
npm.cmd ci
npm.cmd run dev
```

`package-lock.json` 已生成，后续使用 npm，不混用其他包管理器。

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

本轮已实际运行类型检查、4 项自动测试和生产构建。构建成功；Three.js 所在主包约 644 KB（gzip 约 172 KB），有体积提示，后续可再拆包。浏览器检查涵盖 1280×720 桌面和 390×844 窄屏；详细记录见 `docs/开发进度.md`。

## 地址与操作

- `/`：三时总览。
- `/market/noon`、`/market/night`、`/market/morning`：可直接打开的市集。
- `?stall=toys` 等参数表示当前摊位；`product` 表示详情，`panel` 表示上层面板。
- 浏览器返回逐层恢复；Esc 关闭详情、行囊或摊位。
- 进入街道后点击底部店名也可自动走向摊位。只有总览场景区域的滚轮会切时，商品栏的滚动不会改变时段。

生产部署需要把上述地址回退到 `index.html`。本次仅本地运行，没有公开部署或远程推送。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `src/app/mountApp.ts` | 页面、导航、详情、行囊与模拟订单 |
| `src/data/catalog.ts` | 市集、摊位、演示商品与矢量缩略图 |
| `src/data/cart.ts` | 购物车校验、合并、合计 |
| `src/scenes/createOverview.ts` | 场景、角色移动、镜头、切时与 GLB 接入 |
| `src/scenes/craft.ts` | 可复用建筑、摊位、人物与商品模型 |
| `src/scenes/productViewer.ts` | 商品环绕、复位、款式变色与资源清理 |
| `src/scenes/motion.ts` | 后台恢复时有界的动画时间步长 |
| `src/styles.css` | 国风页面与窄屏布局 |
| `tests/` | 购物车与动画计时回归测试 |
| `public/assets/models/stalls/reference-stall.glb` | 用户参考文件夹中的摊位模型 |
| `docs/` | 需求、进度、验收和素材来源 |

已保留原始策划与美术参考。下一步建议先验收总览和四个摊位的风格，再针对选定样板提高人物、纹理与陈列精度。正式商品、真实交易、最终命名和主角身份仍待定。
