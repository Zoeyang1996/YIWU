# 义乌三时市集 YIWU

基于 Three.js 的国风交互市集网页。用户在午市、夜市和早市之间切换，以第三人称角色逛街，与摊主互动并浏览商品。夜市以温暖、趣味化的中式志怪为主要特色。

已建立分类资产目录和 Three.js + TypeScript + Vite 网页源文件，包含正交相机、牌楼与摊位占位体块、尺寸适配及失败重试。当前环境未找到 Node.js/npm，尚未安装依赖、生成锁文件或验证运行；T01 仍待运行验收。时段切换、漫游与购物尚未实现。

## 启动与检查（待本机验证）

准备 Node.js 22.12 或更高版本以及随附 npm，在本仓库终端执行：

```powershell
npm.cmd install
npm.cmd run dev
```

安装会生成 `package-lock.json`，应与代码一同保存；之后使用 `npm.cmd ci` 按锁文件安装。开发地址以终端输出为准，Vite 默认地址为 `http://127.0.0.1:5173`。不要双击 `index.html` 启动。

```powershell
npm.cmd run typecheck
npm.cmd run build
npm.cmd run preview
```

以上命令已配置，尚未实际执行成功。浏览器打开后检查牌楼和四个摊位是否可见、缩小窗口是否完整显示、刷新是否正常；场景失败时检查提示及重试按钮。当前无持续动画循环，窗口变化时重新绘制。

环境要求参考 [Vite 官方说明](https://vite.dev/guide/)。

1. 阅读 [设计框架](docs/设计框架.md)，了解三级体验和三时段市集。
2. 阅读 [开发进度](docs/开发进度.md)，查看已完成工作和下一任务。
3. 让 AI 按 [AGENTS.md](AGENTS.md) 执行工作，并参照 [阶段任务](docs/阶段任务.md)。
4. 在浏览器按 [验收清单](docs/验收清单.md) 检查结果，验收后再保存 Git 版本。

## 核心体验

- 一级：正交镜头下的牌楼与市集总览，滚轮或按钮平滑切换午市、夜市、早市。
- 二级：进入独立市集地址，操控角色沿街漫游；点击摊位后运镜至摊主平视构图，右侧显示商品栏。
- 三级：查看商品、选择规格与数量；适合的商品支持三维环绕。
- 全局：跨市集购物车，随时返回总览或切换市集。原型默认采用明确标注的模拟结账。

## 日常工作方式

每次选一个可验收的任务，让 AI 实现并检查，再由你判断画面和体验。任务结束时更新进度文件；确认可用后创建 Git 提交。`commit` 保存本地代码版本，`push` 上传这些版本到 GitHub；上传代码不等于网站已经发布。

这里不保存账号密码、密钥和真实用户订单。依赖、构建输出和本机环境文件已加入忽略规则。美术参考仅作为研究资料，不等同于获准用于公开网站的正式素材。
